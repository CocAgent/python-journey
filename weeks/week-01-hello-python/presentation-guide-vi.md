# Week 01 — Bản giải thích ngắn gọn để trình bày

## 1. Tuần này học gì?

Week 01 giúp em chuẩn bị môi trường lập trình và chạy được chương trình Python đầu tiên. Em làm quen với Python, VS Code, Terminal, Git và GitHub.

## 2. Các khái niệm chính

- **Python:** ngôn ngữ dùng để viết chương trình.
- **Interpreter:** chương trình đọc và thực thi code Python.
- **VS Code:** trình soạn thảo code.
- **Terminal:** nơi nhập lệnh để chạy chương trình.
- **Git:** theo dõi lịch sử thay đổi của code.
- **GitHub:** nơi lưu trữ và chia sẻ repository trên mạng.
- **`print()`:** in thông tin ra màn hình.
- **REPL:** nơi nhập lệnh Python và xem kết quả ngay.

## 3. Ví dụ đơn giản

```python
print("Hello, Python!")
print(2 + 3)
```

Kết quả:

```text
Hello, Python!
5
```

Lệnh chạy file trong Terminal:

```bash
python ten_file.py
```

Trên một số máy Windows, có thể dùng `py ten_file.py`.

## 4. Nếu thầy hỏi Git khác GitHub thế nào?

Git quản lý lịch sử phiên bản trên máy tính; GitHub lưu repository trực tuyến để chia sẻ và cộng tác.

## 5. Bài nói ngắn trước thầy

> Thưa thầy, Week 01 giúp em làm quen với môi trường lập trình Python. Em học cách dùng VS Code để viết code, Terminal để chạy chương trình, `print()` để hiển thị kết quả, Git để quản lý lịch sử thay đổi và GitHub để lưu code trực tuyến. Mục tiêu là em có thể tự tạo, chạy, kiểm tra và lưu chương trình đầu tiên của mình.

## 6. Em cần nhớ

**Viết code → chạy chương trình → kiểm tra kết quả → lưu thay đổi bằng Git/GitHub.**

Tài liệu này bổ sung phần giải thích bằng tiếng Việt; không thay thế bài học, bài tập hoặc file code gốc của Week 01.
