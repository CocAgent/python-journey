# Công cụ AI tự chọn — Tuần 01

Đây là **phần mở rộng, không bắt buộc và không cộng/trừ điểm riêng**.
Để hoàn thành Tuần 01, người học chỉ cần Python 3.12+, terminal, editor,
Git/GitHub, `print()`, đọc lỗi và một commit do chính mình hiểu.

## Chọn một cách học

| Công cụ | Dùng khi nào? | Kết quả phải tự kiểm tra |
|---|---|---|
| [Google Antigravity](google-antigravity.md) | Muốn AI hỗ trợ ngay trong editor hoặc dự án local | Chạy file `.py`, đọc output, review `git diff` |
| [ChatGPT kết nối GitHub](chatgpt-github.md) | Muốn AI đọc và giải thích repository đã cấp quyền | Đối chiếu nhận xét với code thật, không nhầm đã push |

Hai dịch vụ **không tự chia sẻ tài khoản hoặc quyền truy cập GitHub** cho
nhau. Nếu chưa có các công cụ này, dùng VS Code và tài liệu môn học bình thường.

## Thực hành 10–15 phút, tự chọn

1. Tự viết một dòng `print("Xin chào Python!")` trong file thực hành
   `ex01_hello.py` trên nhánh được giao.
2. Nhờ **một** công cụ AI giải thích vì sao dòng lệnh chạy được,
   nhưng **không yêu cầu làm hộ toàn bộ bài**.
3. Chạy chính file mình sửa bằng Python; kiểm tra output thật.
4. Dùng `git status` và `git diff` để quan sát thay đổi.
5. Ghi vào [mẫu minh chứng](../evidence-template.md) câu hỏi đã hỏi AI,
   điều bạn tự sửa và cách đã kiểm chứng.

**An toàn:** Không chia sẻ token, mật khẩu, đáp án riêng của lớp hoặc bài của
người khác; không cho agent tự ý xóa file, chạy lệnh nguy hiểm, push/merge hay
thay đổi cấu hình/quyền repository.

Tài liệu tham khảo từ nhà cung cấp có thể đổi giao diện, tên nút và điều kiện
truy cập. Nếu màn hình khác hướng dẫn, xem liên kết chính thức ở từng trang.
