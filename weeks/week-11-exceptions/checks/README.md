## Bộ kiểm mới cho bài sinh viên

Từ gốc repository:

```bash
python weeks/week-11-exceptions/practice/checks/check_practice.py --starter
python weeks/week-11-exceptions/practice/checks/check_practice.py --solutions
```

Chạy bằng standard library, import và gọi hàm thật, kiểm
return/exception type/error message, file trong thư mục tạm
và `finally` ghi event khi TypeError chưa được bắt.
`--starter` mới bắt đầu FAIL (0/4) là đúng. `--solutions`
PASS không chấm code learner và không thay official checker.

Xem [sổ tay dự đoán và debug](../WORKED-EXAMPLES.md).
