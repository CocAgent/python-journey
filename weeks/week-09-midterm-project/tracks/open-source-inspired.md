# Track C — Dự án Python tự chọn, tham khảo 20 nguồn mở được tuyển chọn

## Mục tiêu

Chọn **một** vấn đề nhỏ từ [danh mục 20 dự án](../project-ideas/catalog-20-du-an.md), hoặc đề xuất đề tài Python khác, rồi xây **MVP chạy lại được** dựa trên hàm, vòng lặp, điều kiện và dữ liệu `list/dict` (Tuần 01–08).

Đây là **dự án của nhóm 1–3 sinh viên hoặc cá nhân**, không phải yêu cầu fork cả repo FastAPI, Transformers, OpenClaw hay huấn luyện AI. Không bắt buộc cài package bên thứ ba, dùng AI API, GPU, server, thiết bị robot, hoặc dữ liệu trực tuyến.

**Hướng ngành kinh doanh:** Sinh viên có thể chọn thêm
[13 bài toán từ Saleor, ERP, CRM, marketing và analytics](../project-ideas/commerce-marketing-open-source.md).
Bản giữa kỳ vẫn làm Python CLI ngoại tuyến, không cần thanh toán, email thật,
tracking người dùng hay framework lớn.

## Điều kiện hoàn thành

- Python là ngôn ngữ chính, phiên bản theo khóa **>=3.12**.
- Mô tả input, output, 3–5 hành vi cốt lõi; chia hàm đơn nhiệm.
- Có demo chạy từ lệnh/documentation rõ ràng, dùng dữ liệu ví dụ hợp lệ.
- Ít nhất một test/checklist normal và một edge/invalid; ghi expected & actual.
- Có README, lịch sử Git/commit SHA, một lỗi đã sửa, một điểm còn hạn chế.
- Nêu nguồn thư viện/dữ liệu, giấy phép nếu dùng mã/dữ liệu bên ngoài.
- Nộp [phiếu đề xuất](../project-ideas/phieu-de-xuat-nhom.md), [evidence-template](../evidence-template.md) và demo.

## Phân biệt bắt buộc và mở rộng

| Bắt buộc giữa kỳ | Tùy chọn sau MVP |
|---|---|
| Một chương trình Python nhỏ giải quyết vấn đề | Giao diện Streamlit/Gradio/Pygame |
| Dữ liệu `list/dict`, xử lý bằng hàm và `if/for` | Web API/FastAPI, validation Pydantic, data pandas |
| Hướng dẫn chạy được, thử case biên | PyTorch, Transformers, LangGraph, OpenClaw; CrewAI A01 (chỉ nghiên cứu kiến trúc ở W09) |
| README, Git, minh chứng và đạo đức dữ liệu | Deploy cloud, máy học lớn, phần cứng thật |
