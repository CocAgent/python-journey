# Midterm tracks

Chọn một track phù hợp với điều bạn muốn chứng minh. Cả hai track đều dùng kiến
thức Week 01–08 và cùng evidence template.

## Track A — VuaCóc Bot V1

Flagship track: structured course-local state → explainable heuristic → Local
Arena match → baseline evidence.

Đọc [`vuacoc-bot-v1.md`](vuacoc-bot-v1.md).

## Track B — Student Manager

Track thay thế giữ bài toán legacy có giá trị: model learner bằng nested data,
tách các phép tính và tạo report terminal.

Đọc [`student-manager.md`](student-manager.md).

## Track C — Dự án nhóm lấy cảm hứng từ mã nguồn mở

Dựa trên danh mục [20 repository được giảng viên cung cấp](../project-ideas/catalog-20-du-an.md), nhóm 1–3 sinh viên có thể chọn một đề tài Python nhỏ, trình diễn được, với đầu vào/đầu ra và minh chứng rõ. Có thể đề xuất dự án Python khác ngoài danh sách.

- [Yêu cầu Track C](open-source-inspired.md)
- [Danh mục và 20 MVP gợi ý](../project-ideas/README.md)
- [Rubric 10 điểm](../project-ideas/rubric-10-diem.md)

Việc dùng framework nâng cao chỉ là phần tùy chọn; MVP Python 01–08 vẫn đủ điều kiện chấm điểm tối đa.

## Shared evidence

Mọi track cần:

- một command chạy local;
- structured data có giải thích;
- functions không phụ thuộc global state không cần thiết;
- normal case và boundary case;
- một bug đã sửa;
- một known weakness;
- commit SHA và README ngắn.
