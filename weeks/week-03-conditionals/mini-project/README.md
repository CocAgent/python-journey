# Mini-project — Decision Ticket

Nhận tên, tuổi và loại vé rồi validate trước khi quyết định giá.

## Definition of done

- input rỗng hoặc tuổi không phải số bị từ chối;
- tuổi ngoài `0..120` bị từ chối;
- `if/elif/else` tạo một price rõ ràng;
- output dùng f-string;
- có normal, boundary và invalid case.

```bash
python weeks/week-03-conditionals/mini-project/starter.py
```

## Bài đệm trước mini-project

Nếu còn nhầm thứ tự `if/elif` hoặc cách kiểm input dạng text,
đọc [WORKED-EXAMPLES.md](../WORKED-EXAMPLES.md) và tự làm
[Lab 01–03](../practice/README.md). Sau đó mới quay lại
Decision Ticket để lập bảng `age/loại vé → nhánh chạy → thông báo`.
Thử tuổi 0, 12, 65, 121 và `abc`; không báo vé hợp lệ khi
input bị từ chối. Ngưỡng/giá của ví dụ chỉ là dữ liệu giả lập.
