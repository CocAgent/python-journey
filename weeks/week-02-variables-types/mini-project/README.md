# 🎓 Python Journey - Week 02 Mini-Project

Dự án nhỏ này là bài tập thực hành thuộc **Tuần 02** trong chuỗi hành trình học lập trình Python, tập trung vào kiến thức về biến (variables) và các kiểu dữ liệu (data types).

## 📌 Tính năng chính (`StudentCard.py`)
Chương trình cho phép nhập và tự động căn chỉnh hiển thị thông tin thẻ sinh viên một cách trực quan trên Terminal bao gồm:
*   Họ và Tên 
*   Mã số sinh viên (MSSV)
*   Ngành học
*   Khóa học

## 🛠️ Hướng dẫn cài đặt & Chạy chương trình

### 1. Cài đặt thư viện bắt buộc
Chương trình có sử dụng thư viện `unicode` để xử lý chuỗi ký tự. Bạn cần cài đặt trước khi chạy:
```bash
pip install unicode
```
*(Nếu gặp lỗi, hãy thử lệnh: `pip install unidecode`)*

### 2. Cách chạy ứng dụng
Di chuyển vào đúng thư mục chứa dự án và chạy lệnh sau:
```bash
python StudentCard.py
```
