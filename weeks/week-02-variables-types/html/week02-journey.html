TODO 4 · Tính chỉ số BMI

1.25 / 1.25

Nhập chiều cao (m) và cân nặng (kg) để tính BMI = cân_nặng / (chiều_cao ** 2).

Xem mã Python
chieu_cao = float(input("Chieu cao (m): "))
can_nang = float(input("Can nang (kg): "))
bmi = can_nang / (chieu_cao ** 2)
print(f"BMI: {bmi:.1f}")
THỬ THÁCH

TODO 5 · Đổi giây sang giờ : phút : giây

Tự chọn

Nhập tổng số giây (ví dụ 3661 → 1 giờ 1 phút 1 giây).

Xem mã Python
tong_giay = int(input("Tong so giay: "))
gio = tong_giay // 3600
phut = (tong_giay % 3600) // 60
giay = tong_giay % 60
print(f"{gio} giờ {phut} phút {giay} giây")

Mở file ex03_input_calc.py
ĐẠT

TODO 1 · Tổng, hiệu, tích, thương

1.50 / 1.50

Nhập 2 số bất kỳ để tính 4 phép toán cơ bản.

Xem mã Python
so_1 = float(input("So thu nhat: "))
so_2 = float(input("So thu hai: "))
print("Tong:", so_1 + so_2)
print("Hieu:", so_1 - so_2)
print("Tich:", so_1 * so_2)
print("Thuong:", f"{so_1 / so_2:.2f}" if so_2 != 0 else "Khong the chia cho 0")
ĐẠT

TODO 2 · Hình tròn (π = 3.14159)

1.00 / 1.00

Nhập bán kính r để tính diện tích và chu vi.

Xem mã Python
pi = 3.14159
r = float(input("Ban kinh: "))
print(f"Dien tich: {pi * r ** 2:.2f}")
print(f"Chu vi: {2 * pi * r:.2f}")
ĐẠT

TODO 3 · Tính giá sau giảm

1.00 / 1.00

Nhập giá gốc và % giảm giá để xem số tiền phải trả.

Xem mã Python
gia_goc = float(input("Gia goc: "))
giam = float(input("Phan tram giam: "))
print(f"Gia sau giam: {gia_goc * (1 - giam / 100):.2f}")
THỬ THÁCH

TODO 4 · Máy đổi tiền VNĐ → USD

Tự chọn
