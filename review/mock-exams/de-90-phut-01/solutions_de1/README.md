# Lời giải tham khảo — chỉ dùng sau khi tự làm

Gồm 10 file tương ứng các ý bài. Lời giải mẫu
được kiểm độc lập bằng:

```bash
python review/mock-exams/de-90-phut-01/autograde_de1.py --reference
```

Bài reference đạt điểm cao không chứng minh bài sinh viên
đã hoàn thành, cũng không phải chuẩn chống gian lận.
Câu 5b nhập class `DienThoai` từ Câu 5a để minh họa
tái sử dụng lớp giữa hai module.
