# Mẫu bằng chứng ôn tập (copy vào file cá nhân)

Không nhập mật khẩu, token Remote Desktop hoặc dữ liệu thật.
Không sửa tài liệu chung để nộp bài; tạo bản sao cá nhân.

```text
Tên/nhóm (tự nguyện):
Buổi ôn:
Tuần/khái niệm cần củng cố:
Câu hoặc Lab:
Input và dự đoán:
Actual output:
Trường hợp biên:
Trường hợp invalid:
Exception type (nếu có):
Bug đã sửa và nguyên nhân:
Lệnh self-check --starter:
Kết quả PASS/FAIL:
Một điều em đã hiểu sau khi sửa:
Commit SHA / liên kết bài nộp (nếu được yêu cầu):
```

**Chỉ ghi PASS khi chạy trên code tự viết**, không dùng
`--solutions` thay kết quả của sinh viên. Evidence của ôn tập
tự chọn không thay [PROGRESS.md](../PROGRESS.md) và rubric chính thức.
