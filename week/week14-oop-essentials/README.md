# Week 14 — OOP Essentials · Composition · Basic Inheritance

> Python Journey · Tuần 14/15

## 🎯 Mục tiêu

Sau tuần này, bạn có thể:

- Tạo `class` và `object`.
- Dùng `__init__()` và `self`.
- Tạo instance attributes và instance methods.
- Dùng `__str__()` để hiển thị object dễ đọc.
- Biết khi nào class phù hợp hơn `dict` + functions.
- Hiểu composition và ưu tiên composition khi mô hình phù hợp.
- Hiểu inheritance cơ bản với quan hệ `is-a` tự nhiên.
