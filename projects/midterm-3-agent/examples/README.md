# Ví dụ nhập yêu cầu

Chạy ở thư mục `projects/midterm-3-agent`:

```powershell
python main.py
```

Các đầu vào gợi ý:
- `Tao nhan vat di chuyen trong game 2D`
- `Viet menu cho ung dung quan ly sinh vien`
- `Lap ke hoach kiem thu ham tinh diem trung binh`

**Chú ý:** mọi câu nhập hợp lệ hiện được xử lý bằng cùng một khuôn 3 bước; đây không phải kết quả sinh mã nguồn riêng cho từng nhiệm vụ.

Để kiểm tra lỗi: nhập toàn dấu cách rồi nhấn Enter. CLI phải báo lỗi thay vì tạo kế hoạch.

Tệp dữ liệu minh họa: [test_data/cases.json](../test_data/cases.json). Đây là dữ liệu tham khảo, không phải bằng chứng các ca đã chạy.
