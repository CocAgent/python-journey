- [Microsoft AutoGen](https://github.com/microsoft/autogen) — nghiên cứu phối hợp nhiều agent; không phải dependency hiện tại.
- [CrewAI](https://github.com/crewAIInc/crewAI) — tham khảo luồng công việc nhiều vai trò.
- [LangGraph](https://github.com/langchain-ai/langgraph) — tham khảo luồng điều phối có trạng thái.

## Cách sử dụng
1. Đọc tài liệu để hiểu cách thiết kế, tránh sao chép nguyên dự án.
2. Kiểm tra README, giấy phép và yêu cầu phiên bản tại nguồn trước khi dùng.
3. Nếu tích hợp thư viện, ghi rõ phiên bản, cách cài và kết quả thử nghiệm.
4. Không đưa API key, token hoặc dữ liệu riêng tư lên repository.
