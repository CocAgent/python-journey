## ✨ Điểm nổi bật của dự án

- **💻 Live Python 3 IDE trên trình duyệt:** Tích hợp **Pyodide (WebAssembly)** cho phép tự viết code, nhập `input()` trực tiếp từng dòng và xem kết quả/Traceback thật giống VS Code.
- **🧪 Thực hành tương tác theo từng TODO:** Nhập dữ liệu trực tiếp cho các bài tập `exercises/`, `practice/` và Mini-project **Thẻ Sinh Viên**.
- **🛠️ Phòng Lab Lỗi phổ biến & Cách sửa:** Tổng hợp 6 lỗi hay gặp (`ValueError`, `TypeError`, `ZeroDivisionError`, `NameError`, lỗi nối chuỗi...) kèm nút so sánh bản LỖI / ĐÃ SỬA.
- **📝 Phiếu Minh Chứng tự động:** Ghi chú lỗi đã sửa, lưu cục bộ và xuất nhanh Markdown để nộp bài.
- **🌗 Giao diện hiện đại:** Hỗ trợ chế độ Sáng / Tối, responsive tốt trên cả máy tính và điện thoại.
